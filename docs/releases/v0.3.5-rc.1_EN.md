# Windows ISO Builder v0.3.5-rc.1 — Final Release Candidate

## Highlights

v0.3.5-rc.1 is the final Release Candidate before v1.0.0. It adds no product features and is intended to freeze the completed v0.3.4 Network/Proxy scope, final GUI polish, cleanup, security/package audit, documentation, metadata, and validation hardening.

> [!WARNING]
> This is a prerelease RC. Install it only if you are ready to perform manual acceptance and, if needed, roll back to the previous ZIP. Real proxy, icon/high-DPI, and ISO E2E checks are not PASS until actually performed.

## Implemented

- ApplicationVersion: `0.3.5-rc.1`;
- GUI Version/FileVersion: `0.3.5-rc.1` / `0.3.5.1`;
- PowerShell ModuleVersion: `0.3.0`;
- Backend Contract SchemaVersion: `1`;
- BuildPlan SchemaVersion: `1`;
- the v0.3.4 Network/Proxy scope is preserved without expansion;
- the GUI does not save a proxy password without a username;
- proxy configuration/credential/connection/authentication failures show actionable RU/EN messages;
- confirmed spacing issues in Build/About/Catalog were fixed;
- `.gitignore` and the package denylist were tightened for generated/local artifacts;
- RC docs, release notes, and the validation matrix were prepared.

No manual PASS is claimed by these release notes.

## NOT RUN

- Explorer/taskbar/high-DPI visual icon checks;
- packaged GUI RU/EN visual pass for Build, Catalog, Settings, Help, and About;
- real Custom HTTP proxy Test connection;
- real Custom SOCKS5 proxy Test connection;
- generated downloader/aria2 through a real proxy;
- Direct traffic observation;
- full packaged GUI ISO E2E;
- external feedback/update acceptance after the repository/tracker is publicly reachable;
- public v1.0.0 release actions.

## Known limitations

- The repository/tracker may remain private until release action, so external unauthenticated update/feedback acceptance may be unavailable.
- The application has no self-updater: it only opens the official GitHub release page.
- Installer/MSIX, USB writing, History/Profiles, customization, telemetry, cloud sync, and plugins are outside the pre-1.0 scope.
