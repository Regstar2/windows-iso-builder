# Windows ISO Builder v0.3.4 — Network Access & Proxy

## Highlights

v0.3.4 completes the planned network layer before the public RC: all supported outbound paths use one Network Policy with System, Direct, and Custom modes. Custom supports HTTP and SOCKS5.

## Added

- global `System / Direct / Custom` Network Policy;
- Custom HTTP and SOCKS5 proxy support;
- GUI Network settings for mode/type/host/port/username/password, Save, Test connection, and explicit credential clearing;
- PowerShell API: `Get-WibNetworkPolicy`, `Set-WibNetworkPolicy`, `Clear-WibProxyCredential`, and `Test-WibNetworkConnection`;
- policy-aware UUP dump API/catalog/metadata and online preflight;
- policy-aware conversion-package download;
- policy-aware GitHub Releases update checks;
- ephemeral loopback HTTP bridge for SOCKS5 and the generated downloader/aria2 path.

## Security

- proxy passwords are stored separately from `network.json` and protected by Windows DPAPI CurrentUser;
- `network.json` contains no plaintext password;
- invalid Custom configuration or unavailable credentials fail closed;
- a Custom proxy failure never causes a silent Direct retry;
- the generated downloader receives only the loopback endpoint `127.0.0.1:<port>` and no upstream proxy host/user/password on its command line;
- Direct clears inherited HTTP/HTTPS/ALL proxy variables for the generated downloader;
- diagnostics additionally redact password/proxy-password/proxy-credential assignments and URLs.

## Compatibility

- ApplicationVersion: `0.3.4`;
