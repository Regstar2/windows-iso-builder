# Windows ISO Builder v0.3.5-rc.1 — Final Release Candidate

## Главное

v0.3.5-rc.1 — финальный Release Candidate перед v1.0.0. Он не добавляет product features и предназначен для заморозки уже готового v0.3.4 Network/Proxy scope, финальной GUI-полировки, cleanup, security/package audit, документации, metadata и validation hardening.

> [!WARNING]
> Это предварительный RC. Устанавливайте его только если готовы выполнить ручную приёмку и при необходимости вернуться к предыдущему ZIP. Реальные proxy, icon/high-DPI и ISO E2E проверки не считаются PASS, пока не выполнены фактически.

## Implemented

- ApplicationVersion: `0.3.5-rc.1`;
- GUI Version/FileVersion: `0.3.5-rc.1` / `0.3.5.1`;
- PowerShell ModuleVersion: `0.3.0`;
- Backend Contract SchemaVersion: `1`;
- BuildPlan SchemaVersion: `1`;
- сохранён v0.3.4 Network/Proxy scope без расширения;
- GUI не сохраняет proxy password без username;
- proxy configuration/credential/connection/authentication failures показывают понятные RU/EN действия;
- исправлены подтверждённые spacing issues в Build/About/Catalog;
- усилены `.gitignore` и package denylist для generated/local artifacts;
- подготовлены RC docs, release notes и validation matrix.

## Automated PASS

Автоматический PASS не заявляется этим файлом до фактического запуска на exact SHA. Требуемая команда:

```powershell
powershell.exe -NoLogo -NoProfile -ExecutionPolicy Bypass -File .\tools\Invoke-ReleaseValidation.ps1 -Full
```

## Manual PASS

Manual PASS не заявлен этим release note.

## NOT RUN

- Explorer/taskbar/high-DPI visual icon checks;
- packaged GUI RU/EN visual pass по Build, Catalog, Settings, Help, About;
- real Custom HTTP proxy Test connection;
- real Custom SOCKS5 proxy Test connection;
- generated downloader/aria2 через real proxy;
- Direct traffic observation;
- full packaged GUI ISO E2E;
- external feedback/update acceptance после публичной доступности repository/tracker;
- public v1.0.0 release actions.

## Known limitations

- Репозиторий/трекер может оставаться private до release action, поэтому внешний unauthenticated update/feedback acceptance может быть недоступен.
- Приложение не содержит self-updater: оно только открывает official GitHub release page.
- Installer/MSIX, USB writing, History/Profiles, customization, telemetry, cloud sync и plugins не входят в pre-1.0 scope.

## Артефакты

Планируемый asset: `windows-iso-builder-v0.3.5-rc.1.zip`.

SHA-256 не указан в source-документе, потому что финальный checksum должен быть рассчитан только для фактически опубликованного release artifact.
