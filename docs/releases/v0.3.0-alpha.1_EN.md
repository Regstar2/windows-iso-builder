# Windows ISO Builder v0.3.0-alpha.1 — GUI MVP

Date: 2026-08-18

## Overview

`v0.3.0-alpha.1` introduces the first Windows GUI on top of the stabilized PowerShell backend. The backend is not rewritten: the WPF client uses only `Invoke-WibBackend.ps1`, Backend Contract Schema v1, and BuildPlan Schema v1.

## Added

- C# / .NET 10 WPF GUI targeting `net10.0-windows`;
- Quick Mode for Windows 11/10 through backend `GetRecommendedBuild`;
- Catalog Mode through `SearchBuilds`, architecture, Preview, and a servicing-record display filter;
- dynamic languages and editions from the backend;
- multi-edition selection, ESD/WIM, and existing build options;
- `CreateBuildPlan` and preflight UX;
- asynchronous `ExecuteBuildPlan` plus an incremental NDJSON event reader;
- cooperative cancellation through `CancelBuild`;
- success/error/cancelled states, log/folder actions, and SHA-256 copy;
- GUI logging under `%LOCALAPPDATA%\WindowsISOBuilder\logs`;
- C# unit/integration tests;
- `tools/Build-Gui.ps1`;
- self-contained `win-x64` publishing and packaged `WindowsISOBuilder.exe --backend-smoke`;
- RU/EN GUI architecture documentation.

## Compatibility

- ApplicationVersion: `0.3.0-alpha.1`;
- PowerShell ModuleVersion: `0.3.0`;
- Backend Contract SchemaVersion: `1`;
- BuildPlan SchemaVersion: `1`;
- `Start-Builder.cmd`, `Start-Builder.ps1`, TUI, and CLI remain supported;
- the GUI runs as `asInvoker`; elevation remains owned by the backend.

## Boundary

The GUI does not import the PowerShell module directly, invoke private functions, parse `Write-Host`, transcripts, aria2/converter output, or manage the aria2/DISM process tree. Errors are classified by `error.code`; compatibility is determined by `contractSchemaVersion`.

## Package

The release ZIP contains a self-contained `win-x64` GUI together with the existing PowerShell backend/TUI/CLI. End users do not need a separately installed .NET Runtime. No installer/MSIX is added in this release.
