# Windows ISO Builder v0.3.4 — Network Access & Proxy

## Главное

v0.3.4 завершает запланированный сетевой слой перед public RC: все поддерживаемые outbound-пути используют одну Network Policy с режимами System, Direct и Custom. Custom поддерживает HTTP и SOCKS5.

## Добавлено

- глобальная Network Policy `System / Direct / Custom`;
- Custom HTTP и SOCKS5 proxy;
- Network settings в GUI: mode/type/host/port/username/password, Save, Test connection и явная очистка credential;
- PowerShell API: `Get-WibNetworkPolicy`, `Set-WibNetworkPolicy`, `Clear-WibProxyCredential`, `Test-WibNetworkConnection`;
- policy-aware UUP dump API/catalog/metadata и online preflight;
- policy-aware conversion-package download;
- policy-aware GitHub Releases update checks;
- ephemeral loopback HTTP bridge для SOCKS5 и generated downloader/aria2.

## Безопасность

- proxy password хранится отдельно от `network.json` и защищается Windows DPAPI CurrentUser;
- `network.json` не содержит plaintext password;
- Custom configuration/credential failures работают fail-closed;
- Custom proxy failure не запускает silent Direct retry;
- generated downloader получает только loopback endpoint `127.0.0.1:<port>` и не получает upstream proxy host/user/password в command line;
- Direct очищает inherited HTTP/HTTPS/ALL proxy variables для generated downloader;
- diagnostic sanitizer дополнительно редактирует password/proxy-password/proxy-credential assignments и URL.

## Совместимость

- ApplicationVersion: `0.3.4`;
- GUI Version/FileVersion: `0.3.4` / `0.3.4.0`;
- PowerShell ModuleVersion: `0.3.0`;

ModuleVersion остаётся независимой линией версии модуля в текущем `0.3.x` release train. Network Policy является runtime/user setting и не добавляется в BuildPlan v1.
