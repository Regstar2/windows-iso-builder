# Windows ISO Builder v0.2.1-alpha.1 — Backend Contract

Дата: 2026-08-18

## Назначение релиза

`v0.2.1-alpha.1` — архитектурный релиз перед будущим GUI. Он добавляет стабильный машиночитаемый контракт над существующим PowerShell backend, не переписывая build pipeline и не меняя текущий TUI/CLI на frontend-specific реализацию.

GUI в этой версии **не реализован**.

## Главное

- новый Backend Contract Schema v1;
- отдельная ASCII-only machine entry point `Invoke-WibBackend.ps1`;
- UTF-8 JSON request/response files;
- optional UTF-8 NDJSON event stream;
- stable machine-oriented error codes;
- controlled DTO boundary с английскими camelCase properties;
- reusable quick-mode recommendation logic для TUI и future frontend;
- structured progress из существующего converter parser;
- event forwarding через существующий elevated plan/result protocol;
- единый runtime source ApplicationVersion в `VERSION`;
- Windows PowerShell 5.1 и PowerShell 7 compatibility остаются целями проекта.

## Error codes v1

`INVALID_REQUEST`, `UNSUPPORTED_SCHEMA`, `INVALID_COMMAND`, `INVALID_ARGUMENT`, `BUILD_NOT_FOUND`, `LANGUAGE_NOT_FOUND`, `EDITION_NOT_FOUND`, `UUP_API_ERROR`, `UUP_API_UNAVAILABLE`, `INVALID_BUILD_PLAN`, `ELEVATION_FAILED`, `BUILD_FAILED`, `INTERNAL_ERROR`.

Список может расширяться внутри schema v1 без breaking change.

## Progress/events

Structured events используют `requestId`, monotonic `sequence`, ISO-8601 timestamp, type, normalized stage и progress object. Основные types: `stage`, `progress`, `completed`, `failed`; также допускаются `warning` и `info`.

Normalized stages: `startup`, `catalog`, `metadata`, `plan`, `preflight`, `download`, `convert`, `verify`, `completed`, `failed`.

Raw aria2 output не является contract data. Один parser в `ConsoleProgress.ps1` обслуживает и console renderer, и structured event sink.

## Security

Backend request рассматривается как untrusted input. Command dispatch ограничен allowlist; `Invoke-Expression`/eval не используются; JSON не исполняется как код. Contract DTO не должен раскрывать signed UUP URLs, product keys, tokens, arbitrary Exception graphs или private PowerShell metadata.

## Не входит в релиз

GUI/WPF/WinUI, C# rewrite, updater, USB/Rufus integration, queue/history/profiles, cache GUI, полный cancellation subsystem, полный preflight следующей версии, полный error taxonomy, собственный UUP downloader/converter и GitHub Actions.

## Проверка перед выпуском

Перед фактическим release/tag должны быть выполнены:

```powershell
powershell.exe -NoLogo -NoProfile -ExecutionPolicy Bypass -File .\tests\Run-Tests.ps1
Invoke-ScriptAnalyzer -Path . -Recurse -Settings .\.psscriptanalyzer.psd1
```

Также требуется `GetVersion` smoke test через `Invoke-WibBackend.ps1` в Windows PowerShell 5.1 и, если доступен, PowerShell 7.

Backend Contract Pester tests используют mocks и не требуют скачивания Windows.
