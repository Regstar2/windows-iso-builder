# v0.2.3-alpha.1 — Validation & Release Hardening

Дата: 2026-08-18

## Цель

Это последний backend-focused релиз перед `v0.3.0` GUI. Он не расширяет пользовательский feature scope: задача версии — сделать существующий PowerShell backend воспроизводимо проверяемым, защитить Backend Contract v1 / BuildPlan v1 от случайных breaking changes и отдельно валидировать release ZIP так, как его получает пользователь.

GUI, WPF/WinUI и C# намеренно отсутствуют.

## Added

- единый `tools/Invoke-ReleaseValidation.ps1` с Quick/Full и opt-in smoke layers;
- machine-readable `validation-result.json` с deterministic exit code;
- централизованный `tools/ReleasePackageConfig.psd1` для logical allowlist/denylist;
- shared release-validation helpers;
- semantic Backend Contract v1 compatibility regression tests;
- baseline regression десяти существующих Backend commands;
- required success/error envelope regression;
- build/preflight/build-result/progress/cancelled DTO/event regression;
- controlled failure-injection coverage structured error codes;
- `tests/fixtures/build-plan-v1.json` и небольшой GetVersion request fixture;
- BuildPlan v1 read/validate/round-trip regression;
- generated `release-manifest.json` внутри package staging;
- release ZIP checksum/open/content/manifest validation;
- extracted-package module/backend smoke с проверкой отсутствия source-checkout leakage;
- limited current tracked-tree/package scan на obvious secrets, private-key blocks, credential assignments, personal absolute paths и generated junk;
- `docs/VALIDATION_MATRIX.md` / `_EN.md`;
- manual E2E result template.

## Changed

- `tools/New-ReleasePackage.ps1` теперь использует общий release manifest config и self-validates staging before ZIP;
- source validation и release package validation явно разделены;
- VERSION поднят до `0.2.3-alpha.1`, ModuleVersion — до `0.2.3`;
- Backend Contract SchemaVersion остаётся `1`;
- BuildPlan SchemaVersion остаётся `1`;
- Backend Contract v1 и BuildPlan v1 зафиксированы как baseline первого GUI;
- documentation claims разделяют Implemented, Automated-ready, Confirmed, Not run и Not required;
- generated `dist/` и `validation-result*.json` исключены из Git.

## Validation workflow

Quick:

```powershell
powershell.exe -NoLogo -NoProfile -ExecutionPolicy Bypass `
  -File .\tools\Invoke-ReleaseValidation.ps1
```

Full safe release validation:

```powershell
powershell.exe -NoLogo -NoProfile -ExecutionPolicy Bypass `
  -File .\tools\Invoke-ReleaseValidation.ps1 -Full
```

Обычный validation workflow не скачивает UUP set, не собирает настоящий ISO и не требует UAC.

Full дополнительно проверяет release ZIP, strict PSScriptAnalyzer policy, PS7 при наличии и controlled PID-tree cancellation smoke с dummy PowerShell processes.

## Release package

Package содержит generated `release-manifest.json`:

```json
{
  "applicationVersion": "0.2.3-alpha.1",
  "moduleVersion": "0.2.3",
  "backendContractSchemaVersion": 1,
  "buildPlanSchemaVersion": 1
}
```

Manifest не содержит timestamp, username, machine name, local path или secrets.

Package smoke выполняется после распаковки в Temp и импортирует module именно из package root.

## Contract compatibility

Schema v1 baseline commands:

`GetVersion`, `SearchBuilds`, `GetRecommendedBuild`, `GetLanguages`, `GetEditions`, `CreateBuildPlan`, `ValidateBuildPlan`, `ExecuteBuildPlan`, `RunPreflight`, `CancelBuild`.

Tests защищают required semantic contract и не запрещают новые optional fields. Breaking rename/removal/semantic change после этого baseline требует SchemaVersion 2.

## Compatibility

- Backend Contract SchemaVersion: `1`;
- BuildPlan SchemaVersion: `1`;
- TUI/CLI/quick mode unchanged by design;
- Windows PowerShell 5.1 remains mandatory target;
- PowerShell 7 support remains optional-compatible;
- WIM/ESD, virtual editions, cache/resume, UAC/elevation, progress/logging and cancellation mechanisms are not rewritten.

## GUI integration boundary

Будущий GUI должен использовать только:

- `Invoke-WibBackend.ps1`;
- Backend Contract Schema v1;
- BuildPlan Schema v1;
- `RunPreflight`;
- `ExecuteBuildPlan`;
- `CancelBuild`;
- `requestId`;
- NDJSON event stream;
- structured error codes.

Private PowerShell functions, console text, aria2 output и localized error message не являются GUI API.

## Scope intentionally absent

GUI, WPF, WinUI, C#, installer, MSIX, updater, history, profiles, queue, USB writer, Rufus integration, dynamic disk estimator, driver injection, customization/debloat, TPM bypass, activation, custom UUP downloader/converter и GitHub Actions.
