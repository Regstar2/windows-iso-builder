# Windows ISO Builder v0.3.3 — Feedback & Update Delivery

## Главное

v0.3.3 добавляет встроенный путь обратной связи и безопасную проверку обновлений через официальный GitHub Releases. UUP/build backend не изменён.

## Добавлено

- GitHub Issue Forms для ошибок и предложений;
- кнопки обратной связи в About;
- Stable/Prerelease update channels;
- ручная проверка обновлений;
- SemVer-aware version comparison;
- release-notes summary и переход только на validated HTTPS `github.com` release URL;
- safe portable update fallback без автоматической загрузки/запуска;
- минимальный network seam для v0.3.4.

## Безопасность

В клиенте нет GitHub PAT. Feedback не прикладывает diagnostics автоматически. Update checker не скачивает и не исполняет release binaries.

## Совместимость

ApplicationVersion `0.3.3`, ModuleVersion `0.3.0`, Backend Contract `1`, BuildPlan `1`.

## Validation status

Фактический current-head validation должен быть взят из PR/Actions. Этот файл не заявляет PASS до реального прогона.

## Ограничения

Repository/tracker пока private, поэтому внешний feedback/update acceptance не считается выполненным. Global proxy policy относится к v0.3.4.
