# Windows ISO Builder v0.2.0-alpha.1

Дата выпуска: 17 августа 2026 года.

`v0.2.0-alpha.1` — первая версия проекта, подготовленная как публичная alpha. Релиз предназначен для раннего использования и обратной связи; он не позиционируется как стабильная версия с полной матрицей проверенных Windows-сборок.

## Главное

- добавлен быстрый сценарий выбора рекомендуемой стабильной Windows 11 или Windows 10 x64 без зашитого номера версии;
- Windows 11 quick mode предпочитает массовый стабильный H2-релиз специализированным H1-веткам;
- каталог автоматически отделяет полноценные Windows-сборки от cumulative/.NET/OOBE и других servicing-пакетов;
- добавлены сортировка и постраничная навигация по каталогу;
- значительно переработана диагностика elevated-процесса: вместо общего `Exit code: 1` родитель получает структурированную причину ошибки;
- добавлены execution/elevated/converter/build-логи;
- вывод `aria2` и конвертера заменён компактной полосой прогресса, полный вывод сохраняется в лог;
- исправлена совместимость с Windows PowerShell 5.1 для UTF-8 private scripts и `Write-Host`;
- добавлены локальные Pester-тесты для новых сценариев;
- проект переведён на MIT License.

## Проверено

Перед подготовкой релиза локальные тесты проекта проходили успешно. Для проекта используются локальные Pester и PSScriptAnalyzer; GitHub Actions не являются частью release gate.

Реальной ручной проверкой подтверждены:

- end-to-end сборка Windows 11 x64 ru-ru до готового ISO;
- multi-edition сценарий Core + Professional;
- UAC/elevated-запуск;
- корректное завершение сборки и отображение пути к ISO;
- build/converter/elevated/execution-логи и передача детальной ошибки родительскому процессу.

Реальная Windows 11 ISO-сборка выполнялась до последнего изменения политики выбора quick mode. Логика предпочтения массового H2-релиза после этого изменения покрыта локальными тестами.

## Что не является release gate этой alpha

Отдельно не требуется и не заявляется как полностью проверенное:

- end-to-end сборка Windows 10;
- принудительный обрыв сети во время `aria2`;
- полная ручная матрица WIM/ESD;
- GitHub Actions.

WIM и ESD остаются поддерживаемыми режимами, однако alpha-релиз не означает, что каждая комбинация формата, редакций и Windows-релиза прошла отдельную ручную проверку.

## Установка

1. Скачайте release ZIP или исходники версии `v0.2.0-alpha.1`.
2. Распакуйте архив в обычный локальный каталог.
3. Запустите `Start-Builder.cmd`.
4. Выберите обычный поиск или `Быстро скачать последнюю Windows`.
5. Следуйте интерактивным подсказкам и подтвердите UAC перед загрузкой/конвертацией.

## Требования

- Windows 10/11 x64;
- Windows PowerShell 5.1 или PowerShell 7;
- права администратора для стадии загрузки и конвертации;
- около 35–50 ГБ свободного места;
- доступ к UUP dump и Microsoft Windows Update/CDN.
