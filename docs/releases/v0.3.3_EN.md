# Windows ISO Builder v0.3.3 — Feedback & Update Delivery

## Highlights

v0.3.3 adds an in-app feedback path and safe update discovery through official GitHub Releases. The UUP/build backend is unchanged.

## Added

- GitHub Issue Forms for bugs and feature requests;
- feedback actions in About;
- Stable/Prerelease update channels;
- manual update checking;
- SemVer-aware version comparison;
- bounded release-note summary and validated HTTPS `github.com` release URL;
- safe portable update fallback without automatic download/execution;
- minimal network seam for v0.3.4.

## Security

The client contains no GitHub PAT. Feedback never attaches diagnostics automatically. The update checker does not download or execute release binaries.

## Compatibility

ApplicationVersion `0.3.3`, ModuleVersion `0.3.0`, Backend Contract `1`, BuildPlan `1`.

## Validation status

Actual current-head validation must come from the PR/Actions run. This file does not claim PASS before execution.

## Limitations

The repository/tracker is still private, so external feedback/update acceptance is not complete. Global proxy policy is the v0.3.4 milestone.
