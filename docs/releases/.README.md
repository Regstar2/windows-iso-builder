# Releases

Публичные заметки к опубликованным версиям.

Для каждой версии поддерживаются два файла:

```text
vX.Y.Z.md       — русский, основной
vX.Y.Z_EN.md    — English
```

Чистый runtime ZIP собирается локально командой:

```powershell
powershell.exe -NoLogo -NoProfile -ExecutionPolicy Bypass -File .\tools\New-ReleasePackage.ps1 -Version X.Y.Z
```

Скрипт включает только runtime-код, основные документы и release notes текущей версии. В пакет не входят `.git`, `tests`, `.github`, логи, `output`, кеши и локальные project-rules. Рядом с ZIP создаётся файл SHA-256.

Файлы release notes создаются из приватных шаблонов в `.project-rules/templates/`. Приватные шаблоны не должны попадать в Git.
