## History semantics

History begins only when the real `ExecuteBuildPlan` operation starts. A remaining persisted Pending entry becomes Interrupted at the next startup. GetVersion/SearchBuilds/GetLanguages/GetEditions/RunPreflight are not history entries.

The History DTO is controlled and excludes arbitrary backend responses, signed UUP URLs, tokens/product keys, environment dumps, exception/stack traces, and complete BuildPlan JSON.

## Repeat semantics

Repeat never auto-starts an ISO build. The historical exact build is resolved again through `SearchBuilds`, followed by current languages/editions. If the exact build is gone, the user explicitly chooses current recommended, Catalog, or Cancel.

## Profile semantics

A Recommended profile stores user intent and resolves the current recommended build on every use. A Pinned profile stores a controlled exact identity. Missing language/edition values are not silently dropped. Recommended fallback for a missing pinned build does not mutate the saved profile automatically.

## Storage/privacy

- `%LOCALAPPDATA%\WindowsISOBuilder\history.json`;
- `%LOCALAPPDATA%\WindowsISOBuilder\profiles.json`;
- independent schemaVersion `1`;
- temp write + flush + atomic replace/move;
- malformed stores are preserved as `*.damaged-*` when possible;
- unknown future schemas are not overwritten by this application version;
- history/profiles are excluded from diagnostics and release ZIP and are not sent over the network.
