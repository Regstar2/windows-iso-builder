# Windows ISO Builder v0.2.0-alpha.1

Release date: August 17, 2026.

`v0.2.0-alpha.1` is the first version prepared as a public alpha. It is intended for early use and feedback and is not presented as a stable release with a fully validated Windows build matrix.

## Highlights

- added a quick workflow that dynamically selects a recommended stable Windows 11 or Windows 10 x64 build without hardcoding a release number;
- Windows 11 quick mode prefers a mainstream stable H2 release over specialized H1 branches;
- the catalog automatically separates complete Windows builds from cumulative/.NET/OOBE and other servicing packages;
- added catalog sorting and pagination;
- substantially improved elevated-process diagnostics: the parent process receives a structured failure reason instead of only `Exit code: 1`;
- added execution/elevated/converter/build logs;
- replaced continuous `aria2`/converter console output with a compact progress display while keeping the full output in logs;
- fixed Windows PowerShell 5.1 compatibility for UTF-8 private scripts and the `Write-Host` wrapper;
- added local Pester coverage for the new workflows;
- moved the project to the MIT License.

## Validation

The project's local test suite passed during release preparation. The project uses local Pester tests and PSScriptAnalyzer; GitHub Actions are not part of the release gate.

Real manual validation has confirmed:

- an end-to-end Windows 11 x64 ru-ru build through a completed ISO;
- a Core + Professional multi-edition workflow;
- UAC/elevated execution;
- successful completion reporting and ISO path display;
- build/converter/elevated/execution logs and detailed error propagation to the parent process.

The real Windows 11 ISO build was completed before the latest quick-mode recommendation-policy change. The updated rule that prefers a mainstream H2 release is covered by local tests.

## Not release gates for this alpha

The following are not required and are not claimed as fully validated for this release:

- a Windows 10 end-to-end build;
- a forced network interruption during `aria2`;
- a complete manual WIM/ESD matrix;
- GitHub Actions.

WIM and ESD remain supported modes, but an alpha release does not imply that every combination of format, editions, and Windows release has been manually tested.

## Installation

1. Download the release ZIP or the `v0.2.0-alpha.1` source snapshot.
2. Extract it to a normal local directory.
3. Run `Start-Builder.cmd`.
4. Choose either the normal search workflow or `Quick download latest Windows`.
5. Follow the interactive prompts and approve UAC before download/conversion begins.

## Requirements

- Windows 10/11 x64;
- Windows PowerShell 5.1 or PowerShell 7;
- administrator privileges for the download/conversion stage;
- approximately 35–50 GB of free disk space;
- access to UUP dump and Microsoft Windows Update/CDN.
