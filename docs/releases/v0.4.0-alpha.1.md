## History semantics

History начинается только в момент реального `ExecuteBuildPlan`. Незавершённый persisted Pending при следующем startup становится Interrupted. History не записывает GetVersion/SearchBuilds/GetLanguages/GetEditions/RunPreflight.

History DTO controlled и не содержит arbitrary backend response, signed UUP URL, token/product key, environment dump, exception/stack trace или полный BuildPlan.

## Repeat semantics

Repeat не запускает ISO автоматически. Exact historical build заново разрешается через `SearchBuilds`; затем GUI получает актуальные languages/editions. Если exact build отсутствует, пользователь явно выбирает current recommended, Catalog или Cancel.

## Profile semantics

Recommended profile хранит intention и каждый раз использует актуальную recommended build. Pinned profile хранит controlled exact identity. Недоступные language/edition не удаляются молча; GUI показывает stale state. Recommended fallback для missing pinned build не изменяет сохранённый профиль автоматически.

## Storage/privacy

- `%LOCALAPPDATA%\WindowsISOBuilder\history.json`;
- `%LOCALAPPDATA%\WindowsISOBuilder\profiles.json`;
- отдельные schemaVersion `1`;
- temp write + flush + atomic replace/move;
- malformed store сохраняется как `*.damaged-*` при возможности;
- unknown future schema не перезаписывается текущей версией;
- history/profiles не включаются в diagnostics или release ZIP и не отправляются в сеть.
