# Архитектура

## Слои

`Start-Builder.cmd` запускает совместимый с Windows PowerShell 5.1 входной скрипт `Start-Builder.ps1`.

Модуль разделён на независимые части:

- `UupApi.ps1` — запросы `listid`, `listlangs`, `listeditions`, нормализация ответов и фильтрация каталога;
- `Cache.ps1` — файловый кеш API, пакетов и рабочих данных;
- `Selection.ps1` — консольный пользовательский интерфейс;
- `Plan.ps1` — сериализуемый план сборки;
- `Builder.ps1` — повышение прав, пакет UUP dump, конфигурация конвертера, запуск aria2/DISM и проверка ISO;
- `Elevation.ps1` — структурированный обмен результатами и диагностикой между повышенным и родительским процессами;
- `ConsoleProgress.ps1` — компактный прогресс конвертера и сохранение подробного вывода;
- `Application.ps1` — интерактивный и неинтерактивный сценарии.

## Поток данных

1. Пользователь вводит свободный поисковый запрос или выбирает быстрый режим.
2. `listid.php` возвращает каталог известных сборок.
3. Локальные фильтры применяются к архитектуре, Preview-статусу и типу записи.
4. Для выбранного UUID запрашиваются языки и редакции.
5. Выбор преобразуется в JSON-совместимый план.
6. План передаётся повышенному процессу PowerShell через временный JSON-файл.
7. UUP dump выдаёт служебный ZIP с `uup_download_windows.cmd` и конвертером.
8. Конфигурация патчится без редактирования пользователем.
9. aria2 загружает или продолжает UUP-файлы с Microsoft CDN.
10. Конвертер создаёт ISO, после чего программа вычисляет SHA-256 и проверяет структуру.
11. Повышенный процесс возвращает родителю структурированный результат с путями к ISO и диагностическим логам либо с конкретной причиной ошибки.

## Множественные редакции

Первая выбранная редакция используется как базовая для UUP-набора. Остальные передаются в `vAutoEditions`, а `StartVirtual` включает штатный механизм virtual editions. Проект не модифицирует WIM самостоятельно.

Не все комбинации редакций гарантированно преобразуются друг в друга. Для `0.2.0-alpha.1` реальной сборкой подтверждён multi-edition сценарий Core + Professional. Полная матрица возможных комбинаций редакций не является release gate публичной alpha и не заявляется как полностью проверенная.

## Кеш

Ключ рабочего каталога строится из UUID, языка и базовой редакции. Повторный запуск использует тот же каталог, поэтому aria2 может продолжать незавершённые загрузки и проверять уже полученные файлы штатными средствами.

API-кеш имеет TTL, но при сетевой ошибке может использоваться устаревшая копия с явным предупреждением. Отдельный тест с принудительным сетевым обрывом не является release gate `0.2.0-alpha.1`.

## Проверки

Проект использует локальные Pester-тесты и PSScriptAnalyzer. GitHub Actions не являются частью release gate.

Модульные и статические тесты проверяют управляющую логику, но не заменяют реальную ISO-сборку. Текущий статус ручной проверки поддерживается в `docs/IMPLEMENTATION_STATUS.md`.

## Граница доверия

Проект доверяет только структурированному API UUP dump и содержимому полученного ZIP после проверки обязательных файлов. Он не запускает произвольные локальные скрипты вне собственного рабочего каталога.
