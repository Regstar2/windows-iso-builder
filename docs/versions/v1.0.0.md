# v1.0.0 — Stable release

## Цель

Выпустить первый стабильный Windows ISO Builder из принятого `v0.3.5-rc.1` без добавления новых product features. Версия фиксирует готовый GUI, Network/Proxy, feedback/update, diagnostics, packaging и validation baseline.

## Реализовано

- ApplicationVersion синхронизирован с root `VERSION`: `1.0.0`;
- GUI Version: `1.0.0`;
- GUI FileVersion/AssemblyVersion: `1.0.0.0`;
- подготовлены финальные RU/EN README, changelog, release notes, status и validation docs;
- stable release package должен собираться только штатным `tools\New-ReleasePackage.ps1`;
- release flow требует current-tree/package safety scan, full Git-history secret audit, exact-head Full validation, package smoke и checksum verification.

## Совместимость

- PowerShell ModuleVersion: `0.3.0`;
- Backend Contract SchemaVersion: `1`;
- BuildPlan SchemaVersion: `1`.

PowerShell build pipeline, TUI/CLI, Backend Contract commands, BuildPlan v1 и Network Policy architecture не меняются.

## Не входит

History/Profiles, queue, USB writer, installer/MSIX, Windows customization, telemetry, cloud sync, plugin systems, new proxy protocols, self-updater, custom UUP downloader/converter и другие новые product features.

## Validation

Этот документ не заявляет automated или manual PASS. Фактический PASS относится только к exact SHA финального validation run. Manual proxy, icon, high-DPI и real ISO E2E checks остаются NOT RUN, пока не выполнены реально.
