# v0.3.3 — Feedback & Update Delivery

## Цель

Закрыть обязательные pre-public требования Feedback и Update Delivery без изменения существующего UUP/build backend.

## Реализовано

- GitHub Issue Forms: bug report и feature request;
- About actions RU/EN для открытия forms без PAT/OAuth;
- update channel в Settings: Stable (default) / Prerelease;
- ручной Check for updates;
- GitHub Releases API как единственный metadata source;
- собственный SemVer parser/comparer для precedence и prerelease;
- draft filtering, stable/prerelease policy, malformed-tag tolerance;
- bounded release notes;
- whitelist открываемого update URL: только HTTPS `github.com`;
- безопасный portable fallback: открыть официальный release page, без self-download/self-execute;
- `IHttpClientProvider` seam для общей network policy следующей версии;
- persisted update channel;
- RU/EN localization и regression coverage;
- tracked v10-derived project rules и release roadmap.

## Совместимость

- ApplicationVersion: `0.3.3`;
- GUI Version/FileVersion: `0.3.3` / `0.3.3.0`;
- ModuleVersion: `0.3.0`;
- Backend Contract SchemaVersion: `1`;
- BuildPlan SchemaVersion: `1`.

PowerShell build pipeline, TUI/CLI и Backend Contract commands не изменены.

## Не входит

Global proxy policy, HTTP/SOCKS5, History/Profiles, installer, USB writer и новые build features. Proxy — отдельная v0.3.4.

## Validation

Automation/manual PASS не заявляется этим документом. Фактические результаты относятся к exact SHA PR и self-hosted run.
