# v0.3.2 — Navigation, settings and help

## Goal

Simplify the GUI shell after v0.3.1 manual acceptance: free more space for working pages, move utility controls out of the footer, add dedicated Settings/Help sections, and make the primary build workflow visually sequential.

## Changes

- removes the internal top Windows ISO Builder header and moves the application name/version into the left navigation;
- renames Quick to Build;
- navigation now contains Build, Catalog, Settings, Help, and About without a large empty split between navigation groups;
- moves application status into the footer next to `UUP dump / Microsoft CDN`;
- moves interface language, theme, and diagnostics package creation into Settings;
- adds persisted System, Light, and Dark theme choices; explicit Dark applies a dedicated dark shell palette;
- About shows the application description, version, and GitHub repository link;
- Help contains the basic ISO workflow, Catalog explanation, and troubleshooting guidance;
- makes the Catalog filter row responsive so controls wrap onto another line instead of hiding the Search button when width becomes constrained;
- allows horizontal scrolling in the Catalog grid when the window is narrow;
- highlights only the next required Build workflow step with the system accent color: Get recommended → choose edition → Check readiness → Create ISO;
- when a build comes from Catalog, Get recommended is skipped automatically and guidance starts at edition selection.

## Compatibility

Backend Contract, the PowerShell backend, BuildPlan, and the ISO build workflow are unchanged. GUI assembly/file version is raised to `0.3.2`; root ApplicationVersion and ModuleVersion remain unchanged until the separate release/versioning step.

## Validation

Automated validation should cover WPF build, RU/EN resource parity, Build as the startup page, the navigation structure, persisted theme preference, responsive Catalog filters, and workflow-guidance bindings. Real GUI visual acceptance remains required before merge.
