# v0.3.2 — Navigation, settings and help

## Goal

Simplify the GUI shell after v0.3.1 manual acceptance: free more space for working pages, move utility controls out of the footer, and add dedicated Settings, Help, and About sections.

## Changes

- removes the internal top Windows ISO Builder header and moves the application name/version into the left navigation;
- renames Quick to Build;
- navigation now contains Build, Catalog, Settings, Help, and About;
- moves application status into the footer next to `UUP dump / Microsoft CDN`;
- moves interface language, theme, and diagnostics package creation into Settings;
- adds persisted System, Light, and Dark theme choices;
- About shows the application description, version, and GitHub repository link;
- Help contains the basic ISO workflow, Catalog explanation, and troubleshooting guidance;
- gives the Catalog search button and neighboring controls an explicit 36-DIP height to prevent Fluent-theme clipping.

## Compatibility

Backend Contract, the PowerShell backend, BuildPlan, and the ISO build workflow are unchanged. GUI assembly/file version is raised to `0.3.2`; root ApplicationVersion and ModuleVersion remain unchanged until the separate release/versioning step.

## Validation

Automated validation should cover WPF build, RU/EN resource parity, Build as the startup page, the new navigation structure, persisted theme preference, and Catalog search clipping invariants. Real GUI visual acceptance remains required before merge.
