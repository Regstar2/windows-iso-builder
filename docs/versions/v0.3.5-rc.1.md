# v0.3.5-rc.1 — Public Release Hardening

## Цель

Подготовить финальный Release Candidate перед v1.0.0 без добавления product features. Версия замораживает v0.3.4 Network/Proxy scope и закрывает только подтверждённые polish, cleanup, security/package, documentation, metadata и validation-hardening задачи.

## Реализовано

- ApplicationVersion синхронизирован с root `VERSION`: `0.3.5-rc.1`;
- GUI Version: `0.3.5-rc.1`;
- GUI FileVersion/AssemblyVersion: `0.3.5.1`;
- proxy password без username отклоняется в GUI до сохранения policy;
- proxy configuration/credential/connection/authentication failures получают понятные RU/EN action mappings в общем error panel;
- исправлены cramped spacing cases для переносимых action-кнопок Build/About и строки выбора Catalog;
- `.gitignore` и release package denylist усилены для validation/test/local network artifacts;
- подготовлены RC release notes и validation matrix с явными NOT RUN manual checks.

## Совместимость

- PowerShell ModuleVersion: `0.3.0`;
- Backend Contract SchemaVersion: `1`;
- BuildPlan SchemaVersion: `1`.

PowerShell build pipeline, TUI/CLI, Backend Contract commands, BuildPlan v1 и Network Policy architecture не меняются.

## Не входит

History/Profiles, queue, USB writer, installer/MSIX, Windows customization, telemetry, cloud sync, plugin systems, new proxy protocols, self-updater, custom UUP downloader/converter и другие новые product features.

## Validation

Этот документ не заявляет automated или manual PASS. Фактический PASS относится только к exact SHA финального validation run. Manual proxy, icon, high-DPI и real ISO E2E остаются NOT RUN, пока не выполнены реально.
