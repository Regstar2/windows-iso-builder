# v0.3.2 — Navigation, settings and help

## Цель

Упростить оболочку GUI после ручной приёмки v0.3.1: освободить место под рабочие страницы, убрать служебные элементы из нижней панели и добавить отдельные разделы для настроек, помощи и информации о приложении.

## Изменения

- верхний внутренний header Windows ISO Builder удалён; название и версия перенесены в левую навигацию;
- раздел «Быстрый» переименован в «Сборка»;
- навигация содержит «Сборка», «Каталог», «Настройки», «Помощь» и «О приложении»;
- строка состояния перенесена в нижнюю панель рядом с `UUP dump / Microsoft CDN`;
- язык интерфейса, тема и создание диагностического пакета перенесены в «Настройки»;
- добавлен выбор темы: как в Windows, светлая, тёмная;
- выбранная тема сохраняется в пользовательских настройках;
- «О приложении» показывает описание, версию и ссылку на GitHub;
- «Помощь» содержит краткий сценарий создания ISO, описание каталога и действия при ошибке;
- кнопка «Найти» и соседние элементы каталога получили явную высоту 36 DIP, чтобы не обрезаться Fluent-темой.

## Совместимость

Backend Contract, PowerShell backend, BuildPlan и процесс сборки ISO не изменяются. GUI assembly/file version повышена до `0.3.2`; root ApplicationVersion и ModuleVersion остаются без изменений до отдельного release/versioning шага.

## Проверка

Автоматические проверки должны подтвердить сборку WPF, RU/EN parity, старт на странице «Сборка», новую структуру навигации, сохранение темы и отсутствие clipping у поисковой строки каталога. Визуальная проверка реального GUI остаётся обязательной перед merge.
