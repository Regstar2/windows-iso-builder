# v0.3.3 — Feedback & Update Delivery

## Goal

Close the required pre-public Feedback and Update Delivery requirements without changing the existing UUP/build backend.

## Implemented

- GitHub Bug Report and Feature Request Issue Forms;
- RU/EN About actions that open forms without PAT/OAuth;
- Settings update channel: Stable (default) / Prerelease;
- manual Check for updates;
- GitHub Releases API as the only metadata source;
- SemVer parser/comparer with prerelease precedence;
- draft filtering, channel policy, malformed-tag tolerance;
- bounded release notes;
- update URL allowlist: HTTPS `github.com` only;
- safe portable fallback: open official release page, no self-download/self-execute;
- `IHttpClientProvider` seam for the next release's global network policy;
- persisted update channel;
- RU/EN localization and regression coverage;
- tracked v10-derived project rules and release roadmap.

## Compatibility

- ApplicationVersion: `0.3.3`;
- GUI Version/FileVersion: `0.3.3` / `0.3.3.0`;
- ModuleVersion: `0.3.0`;
- Backend Contract SchemaVersion: `1`;
- BuildPlan SchemaVersion: `1`.

The PowerShell build pipeline, TUI/CLI, and Backend Contract commands are unchanged.

## Out of scope

Global proxy policy, HTTP/SOCKS5, History/Profiles, installer, USB writer, and new build features. Proxy support is the separate v0.3.4 milestone.
