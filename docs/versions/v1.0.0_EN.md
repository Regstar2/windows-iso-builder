# v1.0.0 — Stable release

## Goal

Ship the first stable Windows ISO Builder release from the accepted `v0.3.5-rc.1` without adding new product features. This version finalizes the existing GUI, Network/Proxy, feedback/update, diagnostics, packaging, and validation baseline.

## Implemented

- ApplicationVersion is synchronized with root `VERSION`: `1.0.0`;
- GUI Version: `1.0.0`;
- GUI FileVersion/AssemblyVersion: `1.0.0.0`;
- final RU/EN README, changelog, release notes, status, and validation docs are prepared;
- the stable release package must be built only with `tools\New-ReleasePackage.ps1`;
- the release flow requires current-tree/package safety scanning, a full Git-history secret audit, exact-head Full validation, package smoke, and checksum verification.

## Compatibility

- PowerShell ModuleVersion: `0.3.0`;
- Backend Contract SchemaVersion: `1`;
- BuildPlan SchemaVersion: `1`.

The PowerShell build pipeline, TUI/CLI, Backend Contract commands, BuildPlan v1, and Network Policy architecture are unchanged.

## Out of scope

History/Profiles, queue, USB writer, installer/MSIX, Windows customization, telemetry, cloud sync, plugin systems, new proxy protocols, self-updater, custom UUP downloader/converter, and other new product features.

## Validation

This document does not claim automated or manual PASS. A factual PASS belongs only to the exact SHA of the final validation run. Manual proxy, icon, high-DPI, and real ISO E2E checks remain NOT RUN until actually performed.
