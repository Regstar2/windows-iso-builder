# Windows ISO Builder v0.3.1 — GUI Polish

## Цель

`v0.3.1` полирует WPF GUI, не меняя Backend Contract v1 и не перенося UUP/build-логику из PowerShell backend в C#.

Главное UX-изменение: основной экран «Быстрый» больше не строится как длинная прокручиваемая страница. Выбор Windows, параметры, компактный preflight и постоянная панель состояния сборки размещены в одном responsive layout. Progress bar и действие отмены находятся в постоянной нижней области.

## UI layout

- визуальная навигация `Быстрый / Каталог` оставлена только в левой панели;
- внутренний `TabControl` используется как контейнер страниц без видимых или focusable tab headers;
- Quick Mode не использует page-level `ScrollViewer`;
- параметры и preflight расположены в двух колонках;
- полный список редакций может прокручиваться только внутри собственной collection-area;
- расширенные параметры вынесены в отдельный WPF dialog;
- полный preflight вынесен в отдельный dialog;
- `DataGrid` каталога занимает доступную высоту и прокручивает только собственные строки;
- нижняя строка выбора каталожной сборки остаётся видимой;
- build panel постоянно занимает нижнюю область Quick Mode и переключает `idle / progress / error / result / cancelled` без добавления карточек ниже viewport.

Целевой рабочий размер окна — `1100×700 DIP`; минимальный размер — `960×600 DIP`.

## Theme и DPI

GUI использует системный WPF `ThemeMode="System"`, а manifest объявляет `PerMonitorV2` DPI awareness. Layout остаётся основан на WPF device-independent pixels без ручного масштабирования координат.

## Localization

Поддерживаются `en` (базовый ресурс/fallback) и `ru`. Fallback: requested locale → language family → `en`. Неподдерживаемая системная locale приводит к английскому интерфейсу. Выбор языка из footer сохраняется в пользовательских GUI settings.

Product/data values (`Windows 11`, `WIM`, `ESD`, architecture IDs, build numbers, paths, hashes и backend codes) не переводятся.

## Accessibility и keyboard

Основные controls имеют локализованные UI Automation names там, где native label недостаточен. Tooltips объясняют Preview, servicing entries, WIM/ESD, расширенные параметры, preflight и diagnostics. Скрытые tab headers не участвуют в keyboard focus; основной workflow использует естественный WPF Tab order.

## Window settings

`%LOCALAPPDATA%\WindowsISOBuilder\settings.json` хранит normal bounds, maximized state и UI locale. Повреждённый settings-файл не блокирует запуск. Сохранённые bounds применяются только если окно существенно пересекается с рабочей областью существующего монитора; `Minimized` не сохраняется как startup state.

## Diagnostics

`Собрать диагностический пакет / Create diagnostics package` создаёт ZIP с фиксированными entries:

```text
app-version.txt
environment.json
execution.log
build.log
converter.log
```

`environment.json` строится по allowlist. Logs санитизируются до записи в ZIP. Единый `DiagnosticSanitizer` удаляет/заменяет HTTP/HTTPS URLs, user profile path, username, bearer/token/API-key/secret assignments и Windows product keys. Архив не создаётся через raw `CreateFromDirectory`.

## Compatibility

Не изменены Backend Contract SchemaVersion `1`, BuildPlan SchemaVersion `1`, ownership PowerShell backend, WPF-only boundary, headless smoke без `StartupUri`, one-way read-only progress binding и transport/process safety boundaries.

GUI assembly/file version повышена до `0.3.1`; `AssemblyVersion` сохраняет `0.3.0.0`. Root release `VERSION` и PowerShell ModuleVersion намеренно не меняются до отдельного release/versioning шага.

## Automated coverage

Добавлены/расширены проверки layout invariants, hidden tab navigation, system theme/PerMonitorV2, RU/EN resource parity и placeholders, EN fallback, diagnostics sanitization и ZIP entry set, settings round-trip/off-screen rejection. Фактические CI и manual GUI/DPI/Narrator результаты фиксируются отдельно.
