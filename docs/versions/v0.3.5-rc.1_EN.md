# v0.3.5-rc.1 — Public Release Hardening

## Goal

Prepare the final Release Candidate before v1.0.0 without adding product features. This version freezes the v0.3.4 Network/Proxy scope and covers only confirmed polish, cleanup, security/package, documentation, metadata, and validation-hardening work.

## Implemented

- ApplicationVersion is synchronized with root `VERSION`: `0.3.5-rc.1`;
- GUI Version: `0.3.5-rc.1`;
- GUI FileVersion/AssemblyVersion: `0.3.5.1`;
- the GUI rejects a proxy password without a username before saving the policy;
- proxy configuration/credential/connection/authentication failures have actionable RU/EN mappings in the shared error panel;
- cramped spacing cases were fixed for wrapping Build/About action buttons and the Catalog selection row;
- `.gitignore` and the release package denylist were tightened for validation/test/local network artifacts;
- RC release notes and the validation matrix were prepared with explicit NOT RUN manual checks.

## Compatibility

- PowerShell ModuleVersion: `0.3.0`;
- Backend Contract SchemaVersion: `1`;
- BuildPlan SchemaVersion: `1`.

The PowerShell build pipeline, TUI/CLI, Backend Contract commands, BuildPlan v1, and Network Policy architecture are unchanged.

## Out of scope

History/Profiles, queue, USB writer, installer/MSIX, Windows customization, telemetry, cloud sync, plugin systems, new proxy protocols, self-updater, custom UUP downloader/converter, and other new product features.

## Validation

This document does not claim automated or manual PASS. A factual PASS belongs only to the exact SHA of the final validation run. Manual proxy, icon, high-DPI, and real ISO E2E checks remain NOT RUN until actually performed.
