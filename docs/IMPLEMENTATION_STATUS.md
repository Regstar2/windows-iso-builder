# Статус реализации

## Реализовано

- динамический каталог и свободный поиск;
- фильтры архитектуры и предварительных сборок;
- динамические языки и редакции;
- интерактивный TUI;
- неинтерактивный запуск;
- план сборки и безопасная передача в повышенный процесс;
- кеш API, пакета и UUP-файлов;
- повторные запросы и использование устаревшего API-кеша при сбое;
- WIM/ESD;
- virtual editions;
- журналы, SHA-256 и JSON-метаданные;
- проверка структуры ISO;
- CI и модульные тесты без сети.

## Требует проверки на Windows

- реальная выдача пакета текущим сайтом UUP dump;
- полная загрузка и сборка Windows 10 22H2;
- полная загрузка и сборка стабильной Windows 11;
- Home + Pro через virtual editions;
- восстановление после принудительного обрыва aria2;
- пути с кириллицей в каталоге проекта и результата;
- поведение антивируса и UAC;
- фактический минимальный объём свободного места.

## Не реализовано

- GUI;
- автоматическое обновление приложения;
- очередь сборок;
- сохранённые пользовательские профили;
- прямая запись ISO на USB;
- интеграция с Rufus;
- выбор точного UUID в публичном CLI;
- локализация интерфейса на английский язык.

До завершения Windows-тестов проект должен оставаться приватной alpha-версией.
