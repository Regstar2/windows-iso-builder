# Статус реализации

## Текущая версия

`0.2.0-alpha.1` — публичная alpha.

Проект пригоден для раннего использования и сбора обратной связи, но не позиционируется как стабильный релиз. Документация ниже разделяет реализованные возможности и сценарии, которые проходили реальную ручную проверку.

## Реализовано

- динамический каталог UUP dump и свободный поиск;
- быстрый выбор рекомендуемой стабильной Windows 11 или Windows 10 x64 без зашитого номера версии;
- фильтры архитектуры и предварительных сборок;
- классификация полноценных Windows-сборок и servicing-пакетов;
- постраничный просмотр и сортировка каталога;
- динамические языки и редакции;
- интерактивный TUI;
- неинтерактивный запуск;
- план сборки и безопасная передача в повышенный процесс;
- структурированный результат elevated-процесса и подробная диагностика ошибок;
- отдельные execution/elevated/converter-логи;
- кеш API, пакета и UUP-файлов;
- повторные запросы и использование устаревшего API-кеша при сбое;
- WIM/ESD;
- virtual editions;
- журналы, SHA-256 и JSON-метаданные;
- проверка структуры ISO;
- локальные Pester-тесты и PSScriptAnalyzer;
- совместимость управляющего кода с Windows PowerShell 5.1 и PowerShell 7.

## Подтверждено реальной ручной проверкой

- end-to-end сборка Windows 11 x64 ru-ru до готового ISO;
- сценарий нескольких редакций Core + Professional на реальной сборке;
- UAC/elevated-процесс;
- создание и отображение итогового ISO;
- запись build/converter/elevated/execution логов;
- диагностика ошибок между повышенным и родительским процессом.

Реальная Windows 11 сборка выполнялась до последней корректировки политики quick mode. Новая логика выбора рекомендуемого массового H2-релиза проверяется локальными тестами и не требует отдельной полной ISO-сборки для alpha-релиза.

## Не является обязательной проверкой для 0.2.0-alpha.1

- отдельная end-to-end сборка Windows 10;
- принудительный обрыв сети во время `aria2`;
- отдельная полная ручная матрица WIM/ESD;
- GitHub Actions.

Поддержка соответствующих возможностей не должна трактоваться как гарантия прохождения всех возможных комбинаций. При обнаружении проблем они должны фиксироваться как отдельные дефекты.

## Не реализовано

- GUI;
- автоматическое обновление приложения;
- очередь сборок;
- сохранённые пользовательские профили;
- прямая запись ISO на USB;
- интеграция с Rufus;
- выбор точного UUID в публичном CLI;
- локализация интерфейса на английский язык.

## Проверки перед изменениями

Для изменений в коде используются локальные проверки:

```powershell
powershell.exe -NoLogo -NoProfile -ExecutionPolicy Bypass -File .\tests\Run-Tests.ps1
Invoke-ScriptAnalyzer -Path . -Recurse -Settings .\.psscriptanalyzer.psd1
```

GitHub Actions не являются частью релизного процесса проекта.
