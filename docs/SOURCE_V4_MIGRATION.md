# Миграция исходника v4

Исходный архив v4 содержал один монолитный `Build-WindowsISO.ps1` и три запускаемых `.cmd`. Он исправлял важные практические проблемы:

- корректную работу Windows PowerShell 5.1 с UTF-8 BOM;
- сохранение `.cmd` в CRLF;
- короткий ASCII-путь `C:\UUP-ISO-Work` для сторонних инструментов;
- проверку структуры маленького служебного ZIP вместо ошибочного порога размера;
- SHA-256, JSON-метаданные и журнал;
- повторные сетевые попытки;
- понятное сохранение HTML-ответа вместо ZIP.

Эти решения перенесены в новую архитектуру.

Удалены ограничения исходника:

- фиксированные Windows 10 22H2/19045 и Windows 11 25H2/26200;
- отдельные `.cmd` для заранее выбранных систем;
- одна редакция и один язык по параметрам;
- выбор первой подходящей сборки без пользовательского каталога;
- удаление рабочего каталога, мешавшее полноценному возобновлению загрузки.
