# Manual E2E validation results

Create a small result file for each real Windows ISO validation that was actually executed. Do not mark a scenario as passed from mocks, source tests, or an expected code path.

Suggested file name:

`v0.2.3-alpha.1-windows10-x64-esd-YYYY-MM-DD.md`

Template:

```text
Version: 0.2.3-alpha.1
Date: YYYY-MM-DD
Windows product: Windows 10 / Windows 11
Release/build: <catalog release and build>
Architecture: amd64
Language: ru-RU / en-US
Editions: Professional / Core + Professional / ...
Format: ESD / WIM
Result: PASS / FAIL
ISO size bytes: <integer>
SHA-256: <64 hex>
Validation status: Confirmed / Failed
Notes: <non-sensitive notes>
```

Do not commit:

- the ISO itself;
- UUP files or partial downloads;
- signed UUP/CDN URLs;
- product keys;
- tokens or credentials;
- usernames, machine names, or personal absolute local paths;
- large logs unless a small sanitized excerpt is required to document a defect.
