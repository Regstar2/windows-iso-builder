# Проверка README перед публикацией

## Структура файлов

```text
[ ] В корне есть README.md.
[ ] В корне есть README_EN.md.
[ ] README.md является русской основной версией.
[ ] README_EN.md является английской версией.
[ ] В обоих файлах есть относительная ссылка на другой язык.
```

## Синхронизация языков

```text
[ ] Выбран одинаковый набор разделов.
[ ] Разделы идут в одинаковом порядке.
[ ] Команды и пути совпадают.
[ ] Версии и статусы совпадают.
[ ] Таблицы содержат одинаковые факты.
[ ] Реализованные и планируемые функции не смешаны.
[ ] Ссылки работают в обеих версиях.
[ ] Английский текст читается естественно и не является механической калькой.
```

## Шапка

```text
[ ] Название проекта — единственный заголовок первого уровня.
[ ] Описание занимает не больше двух предложений.
[ ] Переключатель языка расположен после описания.
[ ] Активный язык выделен жирным и не является ссылкой.
[ ] Используется от трёх до пяти badges, если они действительно нужны.
[ ] Все `OWNER`, `REPO`, `WORKFLOW` и `PLATFORM` заменены.
[ ] Каждый badge работает и сообщает полезный факт.
[ ] Release badge ведёт на Releases.
[ ] Build badge показывает реальный workflow, а не статический статус.
[ ] Локальные якоря badges соответствуют языку README.
[ ] Панель badges одинакова по смыслу в обеих языковых версиях.
[ ] Текстовая навигация под badges содержит только существующие ссылки.
[ ] Логотип и скриншоты имеют alt-текст.
```

## Содержание

```text
[ ] С первых строк понятно, что делает проект.
[ ] Указан реальный статус проекта.
[ ] В «Возможностях» перечислено только реализованное.
[ ] «Быстрый старт» содержит кратчайший рабочий путь.
[ ] Ограничения указаны прямо.
[ ] Есть ссылка на подробную документацию.
[ ] Нет пустых разделов.
[ ] Нет разделов, состоящих из одного очевидного предложения.
[ ] README не дублирует полную документацию.
```

## Фактическая точность

```text
[ ] Все команды существуют.
[ ] Все пути существуют.
[ ] Все версии подтверждены.
[ ] Совместимость не заявлена без основания.
[ ] Результат сборки или тестов не заявлен без запуска.
[ ] Экспериментальные функции помечены.
[ ] Будущие функции находятся только в roadmap.
[ ] Нет придуманных badges, ссылок, классов, API и конфигурационных параметров.
[ ] Нет токенов, паролей, приватных URL, персональных данных и локальной конфигурации.
```

## Естественность текста

```text
[ ] Нет пустого вступления.
[ ] Нет повторяющего заключения.
[ ] Один абзац выполняет одну функцию.
[ ] Одна возможность не повторяется в нескольких разделах.
[ ] Нет искусственно симметричных списков и карточек.
[ ] Нет рекламных слов без конкретного доказательства.
[ ] Нет фраз «Важно отметить» и «Следует учитывать», которые можно удалить без потери смысла.
[ ] Общие слова заменены именами команд, файлов, состояний и результатов.
[ ] Тон прямой, спокойный и соответствует читателю.
[ ] Термины совпадают с кодом и документацией.
```

## Оформление

```text
[ ] Заголовки выбраны из общего каталога.
[ ] Условные разделы сохраняют установленный порядок.
[ ] Таблицы используются только для сравнения данных.
[ ] Предупреждения используются по смыслу.
[ ] Скриншоты актуальны и имеют согласованный размер.
[ ] Изображения находятся в docs/assets/.
[ ] Большой changelog не вставлен в README.
```
