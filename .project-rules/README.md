# Project rules

This directory contains the public, project-adapted subset of `universal_project_rules_template_v10` used by Windows ISO Builder.

Mandatory standards:

- `ENGINEERING_PRINCIPLES.md`
- `DEVELOPMENT_WORKFLOW.md`
- `LOCALIZATION_STANDARD.md`
- `FEEDBACK_STANDARD.md`
- `AUTO_UPDATE_STANDARD.md`
- `NETWORK_PROXY_STANDARD.md`
- `RELEASE_STANDARD.md`
- `AI_TEXT_GUARDRAILS.md`

The rules are tracked in Git so contributors and coding agents share the same constraints. They are developer governance and remain excluded from the end-user release ZIP by `tools/ReleasePackageConfig.psd1`.
