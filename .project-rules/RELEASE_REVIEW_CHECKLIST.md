# Проверка релиза перед публикацией

## Версия и Git

```text
[ ] Версия совпадает в tag, release notes, changelog, приложении и имени артефакта.
[ ] Tag создан из нужного commit.
[ ] Рабочее дерево чистое.
[ ] В release не попали случайные изменения.
[ ] Prerelease помечен как prerelease.
[ ] Stable release не содержит alpha/beta/rc-артефакты.
```

## Два языка

```text
[ ] Создан docs/releases/vX.Y.Z.md.
[ ] Создан docs/releases/vX.Y.Z_EN.md.
[ ] Выбран одинаковый набор разделов.
[ ] Разделы идут в одинаковом порядке.
[ ] Версии, даты, команды, assets и checksums совпадают.
[ ] Статус функций совпадает.
[ ] Ссылки между языками работают.
[ ] Английская версия естественна и не является механической калькой.
```

## Текст

```text
[ ] Первое предложение объясняет смысл релиза.
[ ] «Главное» содержит только наиболее важные изменения.
[ ] Каждый пункт описывает наблюдаемое изменение.
[ ] Нет «улучшена стабильность» без конкретного симптома.
[ ] Нет «исправлены мелкие ошибки».
[ ] Нет commit-сообщений без редакции.
[ ] Нет будущих функций в списке изменений.
[ ] Breaking changes выделены отдельно.
[ ] Ограничения и известные проблемы не скрыты.
[ ] Текст проверен по AI_TEXT_GUARDRAILS.md.
```

## Установка, обновление и откат

```text
[ ] Проверена новая установка из финального артефакта.
[ ] Проверен заявленный путь обновления.
[ ] Указана минимальная поддерживаемая предыдущая версия.
[ ] Указано, что происходит с настройками и данными.
[ ] Миграция описана пошагово.
[ ] Сценарий отката реалистичен и проверен либо помечен как непроверенный.
[ ] Риск потери данных указан прямо.
```

## Проверки

```text
[ ] Сборка выполнена из commit релиза.
[ ] Unit-тесты запущены.
[ ] Линтер и статический анализ запущены, если обязательны.
[ ] Интеграционные тесты запущены, если применимы.
[ ] Ручные сценарии перечислены с устройством или средой.
[ ] Не выполненные проверки указаны как «Не проверено».
[ ] Результаты старой версии не выданы за результаты текущей.
```

## Артефакты

```text
[ ] Прикреплены только финальные файлы.
[ ] Имена файлов понятны.
[ ] Платформа и архитектура указаны.
[ ] Размеры соответствуют фактическим файлам.
[ ] SHA-256 вычислены для финальных файлов.
[ ] Checksums в русской и английской версиях совпадают.
[ ] Debug-артефакты не опубликованы как stable.
[ ] В архивах нет секретов, локальных конфигураций и приватных правил.
```

## GitHub Release

```text
[ ] Название совпадает с tag.
[ ] Описание короткое и не дублирует полные release notes.
[ ] Есть ссылки на русскую и английскую версии из tag.
[ ] Compare-ссылка использует правильную предыдущую версию.
[ ] Assets доступны после публикации.
[ ] Release отмечен Latest только при необходимости.
[ ] Ссылки проверены после публикации.
```

## Документация

```text
[ ] CHANGELOG.md обновлён.
[ ] README.md и README_EN.md обновлены, если изменились установка или возможности.
[ ] Документация миграции обновлена.
[ ] Известные проблемы отражены в документации или issue.
[ ] Публичные release notes не ссылаются на приватные файлы.
```
